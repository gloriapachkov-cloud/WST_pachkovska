# Матеріали лабораторної роботи № 3 — RE:BELLE

Ця папка містить проєктні матеріали вебзастосунку салону краси RE:BELLE, підготовлені в лабораторній роботі № 3.

## Архітектурна діаграма

У системі використано трирівневу клієнт-серверну архітектуру: рівень користувацького інтерфейсу, рівень бізнес-логіки та рівень даних. Такий поділ допомагає розмежувати відображення сторінок, обробку записів клієнтів і зберігання інформації.

Файл: `architecture-diagram.png`.

## ER-діаграма бази даних

ER-модель містить сутності `CLIENT`, `MASTER`, `SERVICE` та `APPOINTMENT`. Сутність запису пов’язує клієнта, майстра й послугу та зберігає дату, час і статус запису.

Файл: `er-diagram.png`.

## Каркас інтерфейсу (Wireframe)

Каркас відображає основні блоки сторінки: навігацію, головний екран, послуги, майстрів і контакти. Він демонструє структуру сторінки без детального візуального оформлення.

Файл: `wireframe.png`.

## Візуальний макет (Mockup)

Макет RE:BELLE показує візуальний стиль сайту салону краси, зокрема блок головного екрана, картки послуг і завершальну інформаційну секцію. У звіті лабораторної роботи № 3 макет розміщений на двох сторінках, тому збережений двома частинами.

Файли: `mockup-part1.jpg` і `mockup-part2.jpg`.
