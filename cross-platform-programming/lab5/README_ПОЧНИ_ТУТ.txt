RE:BELLE — лабораторна робота №5, повний вихідний проєкт Expo.

1. Розпакуй архів у окрему теку REBELLE_Lab5_COMPLETE.
2. Відкрий саме цю теку у VS Code (File → Open Folder).
3. У терміналі: npm install
4. Далі: npx expo install --fix
5. Далі: npx expo start --clear
6. Відкрий QR-код на iPhone через Expo Go. Телефон і ПК мають бути в одній Wi-Fi мережі.

Файли App.js, index.js, app.json, package.json і всі використані компоненти включені.
node_modules НЕ включено: пакети встановлюються командою npm install.

УВАГА: цей архів перевірено на повноту файлів, але НЕ було можливості запустити Expo Go на твоєму iPhone. Не називаємо це підтвердженим тестуванням на пристрої.

ПЕРЕВІРКИ ДЛЯ ВИКЛАДАЧКИ:
- Порожнє ім'я/некоректний телефон -> Alert
- Створення запису -> Alert і лічильник
- Статус 'Виконано' через режим Майстер/Адміністратор
- Скасування та окреме видалення запису
- 10–15 записів і прокрутка списку
- Зміна назви в components/Header.js -> Fast Refresh

Обмеження: у поточній структурі FlatList прокручує також заголовок/форму (форма не закріплена зверху). Для буквально точного виконання кроку 6.2 методички це треба доопрацювати.
