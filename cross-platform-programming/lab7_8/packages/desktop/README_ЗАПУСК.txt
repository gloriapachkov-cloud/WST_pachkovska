RE:BELLE DESKTOP — ЛАБОРАТОРНА РОБОТА №6
=====================================

1. Відкрийте папку REBELLE_Lab6_Desktop у VS Code.
2. У терміналі виконайте:
   npm install
   npm start

ДЕМОНСТРАЦІЙНІ АКАУНТИ (лише для локального навчального проєкту):
  Адміністратор: логін admin, пароль Admin2026!
  Майстер:       логін master, пароль Master2026!
  Клієнт:        створіть новий акаунт на вкладці «Реєстрація клієнта».

ВАЖЛИВО: Демонстраційні паролі відомі з цього README і не підходять для
реального салону. Після першого запуску користувачі зберігаються у users.json,
а паролі — як scrypt-хеші з випадковою сіллю. Не використовуйте справжні паролі.

ФУНКЦІЇ
  Клієнт: реєстрація, вхід, створення і видалення власних записів.
  Майстер: вхід, перегляд лише своїх записів, зміна статусів.
  Адміністратор: вхід, усі записи, додавання/видалення послуг і майстрів,
                  створення записів, зміна статусів і видалення.
  Перевірки: обов'язкові поля, номер телефону, дата, години роботи,
             накладення записів до одного майстра.

ДЕ ЗБЕРІГАЮТЬСЯ ДАНІ
  У системній папці Electron app.getPath('userData'):
    notes.json — записи
    users.json — користувачі та хеші паролів
    services.json — послуги
    masters.json — майстри
  Дані залишаються після перезапуску програми.
  Для лабораторної це локальна модель авторизації без сервера/інтернету.

БЕЗПЕКА ELECTRON
  contextIsolation: true, nodeIntegration: false, sandbox: true.
  Доступ до файлів лише через вузький IPC-інтерфейс preload.js.
  Перевірка ролей виконується в main.js, а не тільки в інтерфейсі.

ПЕРЕВІРКА
  1. Увійдіть як admin, створіть запис для майстра Катерина.
  2. Вийдіть та увійдіть як master — побачите свій розклад, змініть статус.
  3. Створіть клієнта, додайте запис, перевірте «Мої записи».
  4. Закрийте застосунок, запустіть npm start знову — записи залишаться.
  5. Для перевірки синтаксису: npm run check.

ПРИМІТКА
  Ім'я майстра у демонстраційному акаунті — «Катерина».
  Якщо адміністратор додає нового майстра, для його персонального входу
  необхідно окремо створити обліковий запис (у цьому навчальному варіанті
  передбачено один демонстраційний акаунт майстра).
